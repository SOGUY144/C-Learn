# C-Learn 🚀

โปรเจกต์ฝึกเขียนโปรแกรมภาษา C / C++

## 📁 โครงสร้างโฟลเดอร์ (Members)
- `FAN/` - พื้นที่ฝึกเขียนและเก็บผลงานของ FAN
- `GUY/` - พื้นที่ฝึกเขียนและเก็บผลงานของ GUY
- `HAN/` - พื้นที่ฝึกเขียนและเก็บผลงานของ HAN

## 💡 คำแนะนำการใช้งาน
1. ทำงานในโฟลเดอร์ของตัวเอง
2. หลีกเลี่ยงการ push ไฟล์ executable (`.exe`, `.o`, `.out`) ขึ้น repository
3. Commit & Push งานของคุณเพื่อแชร์โค้ดร่วมกัน
