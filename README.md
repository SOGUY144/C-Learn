### วิธีเปิดใช้งานเว็บในเครื่อง (Local Development)
```bash
# 1. เข้าไปที่โฟลเดอร์ web
cd web

# 2. ติดตั้งแพ็กเกจ (ทำครั้งแรก)
npm install

# 3. รันเซิร์ฟเวอร์
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### การเปิดออนไลน์ (GitHub Pages)
ระบบมีไฟล์ GitHub Actions Workflow (`.github/workflows/deploy.yml`) เมื่อ Push ขึ้น Branch `main` สามารถเปิดใช้งาน GitHub Pages ใน Settings ของ Repository เพื่อให้เพื่อนทุกคนเปิดดูผ่านมือถือและคอมพิวเตอร์ได้ฟรีตลอด 24 ชม.
